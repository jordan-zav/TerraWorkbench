# TerraWorkbench branding assets

Place the final brand files in this folder:

- <code>terraworkbench-logo.png</code>: complete horizontal logo with wordmark.
- <code>terraworkbench-icon.png</code>: square symbol for QGIS menus, toolbar and dialogs.

Use transparent-background PNG files. The horizontal logo should ideally be at
least 800 px wide, and the square icon at least 512 x 512 px, so QGIS can scale
them cleanly on high-DPI displays.

The current root-level <code>assets/legacy/icon.svg</code> remains the active plugin icon until the new
assets are added and the QGIS metadata and interface references are updated.
