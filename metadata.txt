about=Provides QGIS Processing algorithms for gravity and magnetic raster data using Harmonica, including GRS80, free-air, terrain, complete Bouguer and Airy reductions, IGRF-14 parameters, survey gridding, crossover leveling, microleveling, and optional SimPEG 3D gravity, susceptibility, MVI and joint inversion workflows on Python 3.11 or newer. TerraWorkbench includes its own user-approved dependency manager, adapted from GPLv3 QPIP components, which reads requirements.txt plus the compatible optional requirements-inversion.txt and installs only into an isolated TerraWorkbench directory in the active QGIS profile with per-package progress. TerraWorkbench is an independent community plugin and is not an official Fatiando a Terra, SimPEG or QPIP product.
