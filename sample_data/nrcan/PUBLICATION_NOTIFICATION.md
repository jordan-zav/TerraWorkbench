# Publication notification template

To: `infogdc-infocdg@nrcan-rncan.gc.ca`

Subject: Publication notice — NRCan Open File 5290 sample grids in TerraWorkbench

Natural Resources Canada Geophysical Data Centre,

This message provides notification that TerraWorkbench publishes two small
reference grids from **BC 2004 - G - Hydraulic**, Geological Survey of Canada
Open File 5290, with their original XML metadata:

- `BC_2004_G_Hydraulic_dem.GRD`
- `BC_2004_G_Hydraulic_mag_res.GRD`

Repository: <https://github.com/jordan-zav/TerraWorkbench>

The repository retains the source portal URL, the dataset-specific terms,
checksums and the requested citation. The files are used as reproducible sample
data for testing open-source import into the TerraWorkbench QGIS plugin.

Contact: Jordan Zavaleta (GisGeo Dev), <jordanzav@gisgeo.dev>
