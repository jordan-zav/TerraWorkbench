# Reproducibility packages

Each folder is a frozen package that reproduces the results of one article. Files inside a package are archived evidence and are not part of the QGIS plugin or of the current source; do not edit them.

- [esi-replay-v1](esi-replay-v1/README.md): replay reported in the TerraWorkbench software article for Earth Science Informatics. Evaluated source at revision a4bc358; verify with SHA256SUMS.txt and the package check command.
