# Matriz de afirmaciones y evidencia

| ID | Afirmación defendible | Evidencia | Límite |
| --- | --- | --- | --- |
| C1 | El Core se ejecuta sin QGIS y el plugin expone flujos en QGIS | CI standalone, pruebas de límites y smoke tests QGIS | No equivale a que toda API tenga formulario especializado |
| C2 | La documentación y las interfaces principales ofrecen EN/ES/PT | 84 versiones de capítulos, catálogos y pruebas de localización | Docstrings originales e informes históricos conservan idioma; no hay ensayo humano de accesibilidad |
| C3 | Se verifican seis flujos con datos públicos reales y referencias declaradas | Registro primario de esta repetición y artefactos de salida | Acuerdo con referencia no demuestra calibración universal ni subsuelo verdadero |
| C4 | Dos inversiones de tutorial producen predicciones reproducibles bajo una receta fija | Registro secundario, WRMS, estados CG y contraste Choclo/Geoana | Datos simulados de tutorial, operadores parcialmente compartidos, sin arrays de modelo verdadero |
| C5 | Los canales y recetas conservan procedencia y resultados recargables | Flujo de canales sobre datos británicos, pruebas de storage y API | No es por sí solo una certificación de toda base de ocho millones de filas |
| C6 | Las ejecuciones son auditables y conservan fallos | Congelación, registro completo, métricas históricas y exportador de resultados fallidos | Reproducibilidad por tolerancia; no identidad binaria universal |

No se sostienen equivalencia universal con software comercial, recuperación geológica única, reconstrucción atmosférica completa de radón ni mejora medida de productividad. El título expresa la finalidad de acceso mediante QGIS, no una evaluación social ya realizada.
