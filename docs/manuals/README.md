# Complete manual / Manual completo

28 chapters in each language, from import and channel management to geophysical processing, inversion, uncertainty, APIs and publication.

- [English](en/README.md)
- [Español](es/README.md)
- [Português](pt/README.md)

The [API reference](../reference/api/en.md) derives signatures from the current source. Original technical docstrings and historical validation reports retain their original language; editorial notes, chapters and navigation have three versions. The [practical handbook](../handbook/README.md) supplies shorter method cards.

Figures distinguish conceptual diagrams, controlled numerical examples and actual widget captures using bundled CC0 synthetic data. Captures document the actual interface and artificial values; they do not establish geological recovery. See the [capture record](_meta/captures.json) and [localization record](_meta/localization.json).
