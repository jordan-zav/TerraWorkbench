## adaptive_terrain

Adaptive finite-DEM gravity at explicit stations, with truncation bounds.

Independent Cartesian tree, signed mass groups and analytic near-field prisms.
The reported error bounds concern monopole truncation only, not DEM/density,
floating-point, datum, curvature or omitted outer-terrain uncertainty.

### terrain_gravity_adaptive

    terrain_gravity_adaptive(easting, northing, elevation_m, observation_xyz, *, density_crust, density_water, reference_elevation_m, absolute_tolerance_mgal, leaf_cells=32, max_cells=4000000, max_points=100000, max_tree_nodes=1000000, max_node_visits=10000000, max_prism_evaluations=10000000, canceled=None)

Finite DEM density-contrast attraction, downward positive in mGal.

Increasing uniform east/north axes (cell centres), complete 2-D DEM and
explicit ENU station positions, all metres. Above the reference plane the
contrast is crust density; below it water minus crust, no automatic datum.
Returns attraction only, NOT a complete terrain/Bouguer/tide correction.

A tree preserves separate positive/negative mass, centroids and second
central moments J. Far groups use monopoles only when d>R and the summed
bound 12*G*1e5*J/(d-R)^4 is finite. Largest-bound groups are refined until
the sum of retained bounds meets the absolute tolerance. This follows the
second-order Taylor remainder with
||Hessian(r_z/r^3)|| <= 24/r^4. The source volume lies in radius R about its
mass centre. Near leaves use exact Harmonica prism kernels, not point cells.
Tolerance zero requests all exact prisms. No thin-cell threshold is applied.

Bounds exclude roundoff and model errors, and are not statistical confidence.
Work limits cover tree nodes, visits and exact source/station evaluations,
not wall time or solver RAM. Worst case can still be a dense exact sum.

### layer_property_response

    layer_property_response(values, spacing, *, kind, top_depth_m, thickness_m, field_nt=None, inclination=None, declination=None, max_cells=1000000, canceled=None)

Forward density contrast or induced susceptibility in a level layer.

For k>0, gravity kernel is 2*pi*G*1e5*exp(-kh)*(1-exp(-kt))/k.
Magnetic kernel is F/2*exp(-kh)*(1-exp(-kt))*d**2 with
d=sin(I)+i*cos(I)*(ke*sin(D)+kn*cos(D))/k. Susceptibility mean
produces no external response; uniform density gives the infinite-slab
response. No remanence, self-demagnetization, terrain or datum adjustment.
Complete finite periodic input; no implicit fill, detrend or padding.

### apparent_layer_property

    apparent_layer_property(values, spacing, *, kind, top_depth_m, thickness_m, background, regularization_response, max_inverse_gain, minimum_wavelength_m, field_nt=None, inclination=None, declination=None, max_cells=1000000, canceled=None)

Regularized apparent contrast plus an explicitly chosen background.

Uses conjugate(K)/(|K|**2+lambda**2), with explicit inverse-gain cap and
radial shortest wavelength. lambda is in data-units/property-units;
max_inverse_gain has reciprocal units. A hard wavelength cutoff is used.
The observed mean is always removed and reported; background is prescribed
and never inferred from DC. In magnetic data it is intrinsically invisible.
At zero inclination exactly transverse modes are unobservable. Recovery
strength is returned as resolution_transfer, not geological confidence.
Does not remove IGRF/regional fields, infer geometry or estimate uncertainty.


## archaeology

Native, auditable multiscale survey exploration and feature retention.

Coordinates supplied to array APIs are projected metres. Maps retain source row
order and finite support. Connected regions are thresholded magnetic features;
they carry no age or archaeological classification.

[Fuente](../../../terraworkbench_core/archaeology.py) · [Capítulo](../../manuals/es/23_integracion_experimentos.md)

### catalogue_anomalies

    catalogue_anomalies(grid, transform, *, threshold_nt, min_cells=3, max_features=MAX_FEATURES, canceled=None)

Return signed connected features above an explicit absolute nT threshold.

Threshold applies to the provided grid values: use a residual map when the
input contains the Earth's field. Positive/negative lobes remain separate.
Diameter is the diameter of a circle with the same thresholded area; it is
not a fitted source width. Boundary flags include holes in survey support.

### analyze_grid

    analyze_grid(grid, transform, *, scales_metres=(0.5, 1.0, 2.0, 4.0), threshold_nt, min_cells=3, max_features=MAX_FEATURES, canceled=None)

Return Gaussian backgrounds, residuals, signed catalogues and persistence.

Each scale is Gaussian sigma in metres, not kernel width. Mask-normalised
smoothing uses reflected outer edges and a four-sigma footprint. A residual
is input minus its local background. Both maps keep the original mask.
Persistence counts scales containing a same-polarity thresholded feature
sharing thresholded cells with each catalogue feature. It is a reproducible
detection measure, not a probability or archaeological interpretation.
Catalogue anchors include coarse-only features. Each anchor uses the first
scale where its region occurs. Broader matched lobes do not replace finer
anchors; geometries remain available separately in each scale catalogue.
Return: scale_maps list [{sigma_m, background, residual, features, ...}],
catalogue (all-scale anchors with persistence), and metadata. Arrays are float64.

### analyze_geotiff

### compare_feature_retention

    compare_feature_retention(before, after, transform, *, features=None, threshold_nt, min_cells=3, padding_metres=2.0, reference_labels=None, canceled=None)

Compare anchored reference lobes on common support, without resampling.

features accepts catalogue dictionaries containing polarity and inclusive
row_min/max,col_min/max. When absent, catalogue_anomalies identifies before
lobes above threshold_nt. Expand each reference box by padding_metres and
compare extrema, half-height equivalent diameter, and fragmentation at the
same absolute threshold. Before/after grids must already share geometry and
nT units. Lost support is reported independently, not filled for comparison.
Half-height diameter uses the connected half-peak region containing the peak.
Continuity is largest threshold component / all thresholded cells in the box.
Dominant amplitude and polarity reversal refer to the unpadded reference box.
Loss of the original polarity is tested on its original threshold footprint.
reference_labels optionally supplies a grid of exact catalogue component IDs.
A missing same-polarity detection has no reported peak displacement.

### compare_retention_geotiffs

    compare_retention_geotiffs(before_path, after_path, *, canceled=None, **settings)

GeoTIFF version of compare_feature_retention; reject geometry mismatches.

### compare_multiscale_retention

    compare_multiscale_retention(result, after_path, *, canceled=None, padding_metres=2.0)

Compare processing effects against every original residual-scale catalogue.

The after map is after_grid minus the SAME pre-processing Gaussian background
at each scale. Its background is never re-fitted, so attenuation and shifts
remain measurable in a total-field survey. Return a JSON-ready object with
scale_results and overall counts of scale/feature observations. One physical
feature can occur in several scales; counts are not unique source counts.
All geometry, metre CRS, nT units, and both source file hashes are verified.

### smooth_nine_point

    smooth_nine_point(values, passes=1, canceled=None)

Binomial 3x3 kernel [1,2,1] outer product; valid-weight normalization.

Outside the raster and NoData contribute no weight. Original holes remain
holes after every pass. This is not a claimed gridflt9 reproduction.

### smooth_least_squares_9x9

    smooth_least_squares_9x9(values, passes=2, canceled=None)

Optional GRIDFLT9 least-squares kernel, with approximate edge handling.

Uses the published 15 coefficients without weight normalization. Their
rounded sum is 1.0000001, so a constant has that small gain each pass.
The default is two passes to match the ARCHIE Sandbox smoothing stage.
This is independent of the existing binomial smooth_nine_point default.

Nearest finite cells fill NoData once before convolution; ties use SciPy's
distance_transform_edt ordering. Each pass repeats the outermost cells
outside the array. The original NoData mask is reapplied after all passes.
This preserves shape and holes but does not claim Oasis's proprietary
boundary/NoData preparation. Agreement with GRIDFLT9 is expected only
when the entire radius 4 * passes neighborhood has finite input support.

### circular_median

    circular_median(values, radius=1, canceled=None)

Median over a pixel-centre disk, not an angular/circular-statistics median.

Offsets satisfy dx²+dy² <= radius². Ignore outside/NoData neighbors but
preserve the original missing footprint. Even valid counts use their middle
pair average. Bounded gather blocks avoid a full image x footprint array.

### automatic_gain_control

    automatic_gain_control(values, window=11, floor_fraction=0.05, max_gain=10.0)

Global RMS / local RMS gain, with an RMS floor and gain cap.

Square odd-sized window in pixels; no mean subtraction. Units are retained
algebraically, but amplitude is altered and is unsuitable for inversion.

### monogenic_phase_attributes

    monogenic_phase_attributes(values, spacing, wavelengths_m, *, sigma_on_f, noise_threshold, polarity='both', padding_cells=(0, 0), edge_exclusion_cells=0, max_cells=1000000, canceled=None)

Log-Gabor/Riesz phase symmetry and unweighted phase alignment.

All inputs must be finite; NoData are not filled. Wavelengths and bandwidth
are explicit. noise_threshold has the input field units, is subtracted
from accumulated energies, and is NOT an automatic Rayleigh noise model.

frequency-spread weighting or Kovesi's phase-deviation penalty. This is not
numerical parity with phasecongmono or CET. Even-grid Nyquist axes and

recorded, not an inferred scientifically valid boundary. Normal azimuth

### local_grid_texture

Local standard deviation (input units) and quantized entropy (bits).

The quantization range and odd square window are explicit. Values outside
the range are rejected, not silently clipped. NaN neighbours are omitted
and counted; centres with NaN or insufficient window coverage remain NaN.
Outside-grid support is absent, not reflected or fabricated. Entropy
depends on bins/range/window and is not a lithological classification.

### local_orientation_entropy

    local_orientation_entropy(azimuth_degrees, window_size, *, bin_origin_degrees, bins=18, minimum_count=3, max_cells=1000000, canceled=None)

Axial orientation entropy of sampled directions, not contact density.

Azimuth is clockwise from grid north, modulo 180 degrees. NaN means no
orientation sample. Bin origin is explicit because quantized entropy is

has equal weight, not line length or geological confidence. minimum_count
governs support; orientation entropy does not establish structural genesis.

### stack_transients

    stack_transients(transients, polarity, *, accepted=None, minimum_stack=3, max_elements=5000000)

Polarity-corrected mean, sample standard deviation and SEM per sample.

Rows are independent repeat transients, columns are samples or gates.
polarity is an explicit +/-1 per row. accepted is an optional boolean
shot mask; no automatic outlier rejection. NaNs mark missing individual
samples, zeros remain observations. Too few contributions yields NaN.
SEM assumes independent repeats: it excludes correlated/telluric noise,
instrumental bias, waveform uncertainty and timing jitter.

### gate_recorded_transients

    gate_recorded_transients(times_s, transients, gates_s, *, max_weight_elements=2000000)

Exact boxcar means of piecewise-linearly interpolated recorded samples.

explicit edges in seconds. No extrapolation or center-sample approximation.
NaN in a sample contributing to a gate propagates to that gate; it is not
filled with zero. Gate each repeat BEFORE stacking to retain within-shot
temporal correlation in empirical gate noise. The returned sparse weight
operator also supports external covariance propagation W*C*W.T.

### fit_diffraction_hyperbola

    fit_diffraction_hyperbola(positions_m, travel_times_s, *, time_std_s, initial, velocity_bounds_m_s, max_evaluations=100)

Fit zero-offset point-diffractor t^2=t0^2+4*(x-x0)^2/v^2.

Explicit (x0,t0,v) initial guess and velocity bounds. Homogeneous velocity,
zero antenna separation, flat datum; not a general CMP/tomographic model.

### normal_moveout

    normal_moveout(traces, dt_s, offsets_m, velocity_m_s, *, maximum_stretch, minimum_fold=2)

Constant-RMS-velocity reflection NMO and mean stack on a zero-based axis.

Offset is full source-receiver separation: t=sqrt(t0^2+(offset/v)^2).
Mute unsupported/stretched samples; no amplitude/stretch compensation.
This is an array processor, not automatic velocity analysis or migration.

### hvsr_windows

    hvsr_windows(windows, dt_s, *, vertical_psd_floor, accepted=None)

Unsmoothed per-window H/V using RMS of north/east amplitude spectra.

Shape (window,3,time), component order north,east,up. Hann periodogram,
mean removed, H=sqrt((P_N+P_E)/2), V=sqrt(P_U). Caller-supplied vertical
noise floor in input-unit^2/Hz; invalid ratios remain NaN. Geometric mean
and log spread describe accepted windows, NOT uncertainty in Vs/depth.
No SESAME certification, smoothing, response removal or automatic rejection.

### sta_lta_picks

    sta_lta_picks(traces, dt_s, *, sta_samples, lta_samples, threshold, lta_energy_floor, search_window_s)

First causal trailing energy-ratio crossing in an explicit search window.

Integer STA<LTA; startup before a complete LTA is invalid. Output is a
candidate threshold pick, NOT a calibrated phase classifier or uncertainty.
Filter/detrend, verify polarity/timing and manually review before tomography.

### phase_velocity_image

    phase_velocity_image(traces, dt_s, positions_m, velocities_m_s, *, frequency_range_hz, minimum_amplitude, minimum_traces=3, max_work=5000000)

Phase-shift coherence image for positive apparent velocity on a line.

Uniform increasing receiver spacing; output |mean(exp(i*phase))|^2.
Demeaned Hann-tapered FFT amplitudes divided by sample count. Reject weak
spectral traces using the caller's explicit amplitude floor. Nyquist-alias
cells are masked. This is dispersion imaging, NOT mode picking or Vs
inversion; negative propagation/array geometry need a different contract.
